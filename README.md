# Task Manager App

A full-stack task management application with authentication.

## Features
- User Registration & Login
- JWT Authentication
- Create, Read, Update, Delete Tasks
- MongoDB Database

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express
- Database: MongoDB

## How to Run

### Backend
cd backend
npm install
node server.js

### Frontend
Open index.html in browser
